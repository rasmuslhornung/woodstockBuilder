How to build with Woodstock Robotics
🏠
Welcome to Assembly Viewer
This guide walks you through how to use the app to assemble your Woodstock Robotics structure step by step. Use the arrows below to continue.
🎨
Modules & Kits
Your model is divided into Modules — colour-coded groups of structural elements that belong together. The left panel lists every module. Click a module to inspect it and see what's inside.
🔨
Step-by-step Build Mode
Click a module a second time (or press "Enter Build Mode") to start the step-by-step assembly guide. Use ← Prev and Next → to walk through each element in the correct sequence. The element lights up so you can see exactly where it goes.
🔍
Finding an Element
Not sure where a specific beam goes? Tap the 🔍 Find button in the top bar. Select a kit, then a category — all elements appear in a list. Click any element and the camera flies directly to it in the 3D model.
📖

🚩
Reporting an Issue
Spotted a wrong or damaged element during assembly? Press the 🚩 flag button in the assembly bar, add a short note — and optionally a photo — and your report goes straight to Woodstock Robotics. We'll get back to you quickly.
✅
You're all set!
Close this guide and enter your project code to open your model. Happy building! 🪵
